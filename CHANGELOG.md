# Changelog

User-visible changes are recorded here. Version 1.1.0 is the next release candidate in source; it has not been published.

## [1.1.0] — Unreleased

### Added

- Optional OpenRouter routing for error analysis, fix proposals, and Pilot, with a cloud-processing notice and best-effort credential redaction.
- Bounded, relevance-selected source, test, and related-code context across supported Python, Java, C#, JavaScript, and TypeScript projects.
- Phone-initiated GitHub publishing for a verified one-file fix, with exact destination review and separate laptop confirmation.
- Shared quality checks for frontend build/type checking and backend tests/linting in GitHub Actions.

### Improved

- Refined the desktop control deck and made Android navigation-bar behavior clearer.
- Expanded setup, privacy, supported-behavior, and release documentation.

### Not included in this release

- Google sign-in, OAuth, account management, or remote repository browsing/cloning.
- A separate Matrix Analysis engine, calibrated LLM score, or formal logical-consistency evaluator.
- A Google Play signed or published build.

## [1.0.9] — Previously device-tested build

- Added the Pilot text and voice conversation panel, session-aware prompts, spoken replies, bounded per-device in-memory chat history, and clear/discard behavior.
- Refreshed the blue and amber desktop/mobile theme.
- The core Python repair, passing check, guarded undo, microphone input, and Pilot conversation were reported working on an iQOO on 26 September 2026. This device evidence applies to 1.0.9, not the 1.1.0 candidate.
